
### removing infrastructure
### we can use the terraform destroy command to remove the deployed infra.

$ terraform destroy

### observe the changes and prompted infra details before the proceeding.

### using variables
### let's update the main.tf file with adding the variable information.
### Create a new file called variables.tf with a block defining a new container_name variable.

$ nano variables.tf

variable "instance_name" {
  description = "Value of the EC2 instance's Name tag."
  type        = string
  default     = "terraform-instance"
}

variable "instance_type" {
  description = "The EC2 instance's type."
  type        = string
  default     = "t3.small"
}

variable "region" {
  description = "AWS region for resources"
  type = string
  default = "ap-south-1"
}

### update the main.tf file by adding the variable reference and removing hard-coded container name.

 resource "aws_instance" "app_server" {
   ami           = "ami-08d70e59c07c61a3a"
   instance_type = var.instance_type

   tags = {
     Name = var.instance_name
   }
 }

## also modify the provider block in main.tf file by replacing hard coded value for region with variable name.
### apply the changes

$ terraform apply

### the variables value can also be supplies at the command line using -var option.

$ terraform apply -var "instance_name=new_server_name"
